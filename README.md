# Calculadora de Precificação — Luê Crochê

Calculadora web responsiva para precificar peças de crochê e artesanato. Abre no navegador de celular ou computador, sem instalar aplicativo e sem enviar os valores calculados para um servidor.

## Recursos

- Cálculo do valor da hora, do fio, dos acessórios, da mão de obra e dos custos adicionais.
- Markup ajustável e edição manual do preço de venda.
- Resumo de custo, lucro e margem.
- Prévia e download do orçamento em imagem PNG.

## Site

A publicação é feita pelo GitHub Pages a partir do arquivo `index.html` na raiz. O fluxo de deploy é executado a cada atualização da branch `main`.
